# File drag and drop does nothing under Wayland

Dropping files or folders onto the khz-player window under Hyprland does nothing (checked by hand on 2026-10-21, task 13). handle_drops in src/app/events.rs reads egui raw.dropped_files, which egui-winit fills from winit WindowEvent::DroppedFile; winit 0.30.13 does not implement drag and drop on Wayland, so the list stays empty. Options: run under XWayland when DnD matters (worse scaling and input), implement a wl_data_device drop target directly (smithay-client-toolkit) beside winit, or wait for winit DnD support. Fallbacks that work today: the open-path field (L) and the library. Side note: khz-player.desktop declares MimeType inode/directory, and with Nautilus not installed xdg-mime picks khz-player as the default folder handler; decide whether to keep that entry.
