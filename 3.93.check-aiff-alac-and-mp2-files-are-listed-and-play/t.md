# Check: AIFF, ALAC and MP2 files are listed and play

A17 (1412454). Put an .aiff, an ALAC .m4a and an .mp2 file in a library folder, rescan, and play each. They must appear in the library and play at the right pitch. Any .opus, .wv, .ape or .mpc files leave the library on rescan; that is expected. Not run by Claude: ~/Music has none of these formats.
